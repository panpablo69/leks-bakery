# 🍞 Serwis Internetowy Leks Sp. z o.o. (Pan Pablo / Projekty)

Projekt budowy nowoczesnego, zjawiskowego i zoptymalizowanego serwisu internetowego dla polskiego producenta pieczywa — **Leks Sp. z o.o.** (`leks.com.pl`).

---

## 🏛 Rola Architekta Systemowego (O Mnie)

Ten projekt jest prowadzony i realizowany przeze mnie pod nadzorem **głównego systemu instrukcji Architekt**. 

Działam jako Twój dedykowany **Senior Programista i Architekt Oprogramowania z ponad 15-letnim doświadczeniem komercyjnym**. Moim priorytetem jest dostarczanie kodu najwyższej jakości oraz dobieranie **najlepszych i najnowocześniejszych rozwiązań technologicznych na rynku**:

- **Wydajność i SEO (Opcja A)**: Projekt realizujemy w oparciu o zoptymalizowany pod kątem szybkości ładowania i indeksowania wyszukiwarek stos **HTML5, nowoczesny CSS oraz czysty JavaScript**. Witryna będzie ładować się błyskawicznie, bez zbędnego narzutu ciężkich frameworków.
- **Wizualna Klasa Premium (GSAP)**: Do wdrożenia płynnych, zachwycających efektów przejść, dynamicznej osi czasu w sekcji „O nas” oraz mikro-interakcji używamy biblioteki **GSAP (GreenSock Animation Platform)** – absolutnego lidera w dziedzinie nowoczesnych animacji webowych.
- **Bezpieczeństwo i Niezawodność (Playwright)**: Wdrażamy automatyczne testy E2E (End-to-End) przy użyciu **Playwright**, co gwarantuje poprawne wyświetlanie i działanie witryny na wszystkich urządzeniach (desktop, mobile, tablety).
- **Holistyczna Automatyzacja**: Repozytorium GitHub zintegrowane jest za pośrednictwem **GitHub CLI (`gh`)**, a system raportowania i powiadomień opiera się o automatyczną pętlę **Gmail API** i **Google Drive Backups**.
